# ceremony-proportional: ceremony proportional to the task

Type: decision
Area: core
Proof: `plugins/craftlight/skills/task/SKILL.md:8`

## Gist
The plugin's root principle. We start light (S by default) and escalate only on explicit observable signals — not the other way round.

## Rationale
The main enemy is wasted tokens. Heavy ceremony on a task that doesn't need it is an unrecoverable cost; escalation is cheap, so it's cheaper to start light and raise the level when the facts call for it.
